# Wi-Tuner — Producto

## Visión

Afinador cromático preciso y sencillo para guitarra, bajo y otros instrumentos. La experiencia debe ayudar a identificar una nota, entender si está baja o alta y afinar sin enviar audio a un servidor.

## Alcance del producto

- Afinador cromático con lectura de nota, octava y cents.
- Afinaciones por instrumento, referencia A4 configurable y tonos de referencia.
- Indicadores visuales claros, incluido un modo estroboscópico real.
- Metrónomo y utilidades de práctica como complementos.
- Web y PWA primero; Capacitor comparte el mismo código funcional para Android e iOS.
- Localización en español e inglés.

## Privacidad

No hay cuentas. El audio se procesa localmente, en memoria y con permiso explícito. No se graba ni se transmite. Las preferencias permanecen en el dispositivo y habrá una acción para borrar todos los datos locales.

## Estado actual

La Fase 0 establece la identidad Wi-Tuner, los workspaces, el tipado estricto y las herramientas de calidad. La nueva app y landing son esqueletos ejecutables. La aplicación Laravel existente se conserva temporalmente y no se presenta como la arquitectura final.
